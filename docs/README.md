## 📝 Documentation Standards

### When Adding New Documentation:
1. Place technical docs in `/technical`
2. Place implementation guides in `/guides`
3. Place setup instructions in `/setup`
4. Update this index file
5. Use clear, descriptive filenames
6. Include date and version information

### Naming Conventions:
- Use UPPERCASE for documentation files
- Use underscores for word separation
- Include descriptive suffixes (GUIDE, SUMMARY, INSTRUCTIONS, etc.)
- Example: `FEATURE_NAME_IMPLEMENTATION_GUIDE.md`
